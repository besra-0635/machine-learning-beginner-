# Machine Learning Foundations: Supervised Learning & Regression

This repository contains practical implementations, exercises, and exploratory models covering foundational machine learning concepts based on **Andrew Ng's Machine Learning Specialization** (Coursera / DeepLearning.AI) and hands-on Python workflows.

## Overview & Mathematical Context

As an undergraduate student in Mathematics at Middle East Technical University (METU), my objective is to explore machine learning algorithms through their analytical and computational roots—connecting linear algebra, multivariate calculus, and optimization techniques (e.g., gradient descent, cost functions) with predictive models.

## Current Implementations

- **Univariate Linear Regression:**
  - Predicting continuous values from single feature inputs (e.g., area-to-price, age-to-price mapping).
  - Implementation of cost function evaluation and parameter optimization.
- **Multivariate Linear Regression:**
  - Multi-feature regression modeling (e.g., vehicle age and mileage impacting price).
  - Feature matrix formulation using Pandas DataFrames and Scikit-learn's `LinearRegression` estimator.
- **Predictive Inference & Analysis:**
  - Out-of-sample data prediction and performance inspection.

## Tech Stack & Tools

- **Programming Language:** Python 3.x
- **Core Libraries:** 
  - `scikit-learn` (Model training and predictive estimation)
  - `pandas` (Data manipulation, feature matrix preparation)
  - `numpy` (Vectorized numerical operations)
- **Environment:** Google Colab, Jupyter Notebooks

## Repository Structure

- `linear_regression_exercises.ipynb` - Step-by-step implementations of single and multiple variable linear regression models.
